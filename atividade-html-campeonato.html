Criando sua página oficial para o Campeonato Nacional

Atividade de estruturação de páginas utilizando HTML

📄 Enunciado

Você foi classificado para disputar o Campeonato Brasileiro de Artes Marciais. A organização solicita que cada atleta envie uma página web simples com sua apresentação, categoria, estado de origem, principais conquistas e um link para seu perfil oficial.

Essa página será publicada no site do evento e deverá ser organizada para facilitar a leitura dos visitantes e da imprensa.

❓ Pergunta

Explique como você estruturaria essa página utilizando HTML, indicando quais tags utilizaria para organizar as informações do atleta, criar títulos, parágrafos, listas e links. Justifique também por que é importante utilizar tags semânticas nessa situação.

✏️ Minha resposta

Resposta da atividade

Eu estruturaria a página de forma organizada e objetiva. Inicialmente, utilizaria a tag <header> para apresentar o meu nome e o título da página. Para organizar os títulos e subtítulos, utilizaria as tags <h1>, <h2> e <h3>.

Para apresentar as informações sobre mim, como minha categoria, estado, utilizaria a tag <p>, formando parágrafos claros e bem estruturados. Para destacar minhas principais conquistas, utilizaria listas com as tags <ul> e <li>, facilitando a leitura das informações.

Também utilizaria a tag <a> para inserir links, como o meu perfil ou páginas relacionadas ao Campeonato Brasileiro. Para dividir melhor o conteúdo, utilizaria as tags semânticas <main>, <section> e <footer>.

Considero importante utilizar tags semânticas porque elas permitem organizar melhor a estrutura da página. Além disso, contribuem para a acessibilidade e para que os mecanismos de busca compreendam melhor o conteúdo da página. Dessa forma, criaria uma página organizada, profissional e adequada.
